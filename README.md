# Titanium Fitness (Lanús)

Página del gimnasio. Astro + Tailwind v4, sin librerías de animación.

**En línea:** https://santilauu.github.io/titanium-fitness/

## Verla en tu computadora
```
npm install
npm run dev
```
Abrí http://localhost:4321/titanium-fitness/

## Dónde está cada cosa
- Página: `src/pages/index.astro`
- Estilos y animaciones: `src/styles/titanio.css`
- Efectos: `src/scripts/titanio.js` y `src/scripts/reflector.js`
- Textos, precio y horarios: `src/content/cliente.json`

## Publicación
El sitio compilado vive en la rama `gh-pages` (GitHub Pages). Para actualizarlo: `npm run build` y subir el contenido de `dist` a esa rama.
